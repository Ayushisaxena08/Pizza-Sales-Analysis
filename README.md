# Pizza-Sales-Analysis
End-to-end SQL analysis of a relational pizza sales dataset to extract business insights and revenue trends.

🍕 SQL Pizza Sales Analysis
📌 Project Overview
This project is an end-to-end SQL analysis of a relational Pizza Sales dataset. The goal was to extract meaningful business insights and demonstrate proficiency in writing basic, intermediate, and advanced SQL queries.

📊 Dataset
The dataset consists of four related tables:
orders – Order ID, date, and time
order_details – Order details ID, order ID, pizza ID, quantity
pizzas – Pizza ID, pizza type ID, size, price
pizza_types – Pizza type ID, name, category, ingredients
All dataset files are available in the /dataset folder.

🛠 Skills & Concepts Applied
Multi-table JOINs
Aggregations (SUM, COUNT, AVG)
GROUP BY & filtering
Subqueries
Revenue and sales trend analysis

📈 Key Insights
Total revenue generated
Top-performing pizza categories
Best-selling pizzas by quantity and revenue
Peak ordering times
Customer size preferences
